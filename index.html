    Sobre o PortfolioHUB

    Esta página lista automaticamente os repositórios públicos do GitHub, junto com projetos cadastrados manualmente em projects.json. Cada alteração no repositório passa por Pull Request, revisão e verificações automáticas de segurança antes de ser publicada no GitHub Pages.
