# Apêndice A. Prompts usados com o Google Gemini

Todos os prompts foram enviados ao Gem "Guia PortfolioHUB" (seção 1.6). Após cada resposta, inserir o print correspondente.

## A.1 Planejamento

```
Monte um plano de implantação do PortfolioHUB em 6 etapas, com cronograma
de 20/10 a 25/10, entregáveis por etapa, riscos com mitigação e as
ferramentas do GitHub e do Google Workspace que devo usar em cada uma.
```

## A.2 Configuração do repositório e GitHub Pages

```
Liste, na ordem, as configurações recomendadas para um repositório público
de site estático publicado no GitHub Pages via GitHub Actions: opções de
merge, Pages, ambiente github-pages e permissões do workflow. Explique o
motivo de cada uma.
```

## A.3 Revisão de segurança (conformidade)

```
Revise a segurança do PortfolioHUB com base no OWASP Top 10 e na
documentação do GitHub. Segue a CSP do index.html e os workflows:
[colar a meta Content-Security-Policy e o conteúdo de .github/workflows]
Aponte falhas, o risco de cada uma e a correção. Termine com um checklist.
```

## A.4 Gestão de usuários e Ruleset

```
Quais papéis de acesso devo usar para dono, mantenedor, colaborador e
tutor no repositório portfoliohub? Monte um Ruleset para a branch main
que exija PR, revisão do CODEOWNER e os checks "Validar conteúdo",
"Varredura de segredos" e "Análise estática (JavaScript)".
```

## A.5 Integração final e testes

```
Crie um plano de testes para o PortfolioHUB cobrindo funcionalidade,
responsividade, segurança (CSP, Push Protection, Ruleset) e o deploy
automático. Inclua o resultado esperado de cada teste.
```

## A.6 Apresentação

```
Monte um roteiro de vídeo de 5 minutos apresentando a implantação do
PortfolioHUB: etapas, soluções de segurança, colaboração e desafios
superados. Divida por tempo e diga o que mostrar na tela em cada parte.
```
